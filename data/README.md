# Data

## Source

- Dataset: Bank Marketing, file bank-additional-full.csv (from bank-additional.zip)
- Repository: UCI Machine Learning Repository, https://archive.ics.uci.edu/dataset/222/bank+marketing
- Licence: Creative Commons Attribution 4.0 International (CC BY 4.0). Redistribution is permitted with credit, so the raw file is included in this repository.

## Citation

- Moro, S., Rita, P., & Cortez, P. (2014). Bank Marketing [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5K306
- Moro, S., Cortez, P., & Rita, P. (2014). A data-driven approach to predict the success of bank telemarketing. Decision Support Systems, 62, 22-31.

## Files

- raw/bank-additional-full.csv - 41,188 rows and 21 columns (20 inputs + target y), semicolon-separated
- raw/bank-additional-names.txt - original variable descriptions from the dataset authors

Raw files are never modified; any cleaned data is produced by the notebooks.

## Re-downloading

- Download bank+marketing.zip from the UCI page above.
- Inside it, open bank-additional.zip and copy bank-additional-full.csv and bank-additional-names.txt into data/raw/.
